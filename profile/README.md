# TabletCommittee
A group dedicated towards reverse engineering various graphics tablets.\
Currently very WIP, more info soon.

Bricked devices:
* Wacom Intuos S (CTL-4100) by [notunixian](https://github.com/notunixian), hard brick
* Gaomon M10K Pro by [Patoke](https://github.com/Patoke), possibly hard brick, tablet not recognized when plugged in due to bad flash, can't boot into DFU mode

# TabletCommittee
A group dedicated towards reverse engineering various graphics tablets.\
Currently very WIP, more info soon.

Bricked devices:
* Wacom Intuos S (CTL-4100) by [notunixian](https://github.com/notunixian), hard brick
* Gaomon M10K Pro by [Patoke](https://github.com/Patoke), soft brick, tablet not recognized when plugged in due to bad flash, can be fixed by writing to the FLASH ROM with custom tooling (WIP!)
